# Этап 6 — ресурсы и общие компоненты

Изменения приложения ограничены `ios/Math_Tricks`. Android и ios-legacy используются
только для чтения. Будильник, его звуки и иконки не добавлены.

## Ресурсы

- `Resources/AndroidIcons.xcassets`: 165 SVG из Android VectorDrawable. Сохранены
  viewport, исходные размеры dp, контуры, цвета, alpha, stroke, evenOdd, преобразования
  групп, clip-path и линейные градиенты. Каталог сохраняет векторное представление,
  иконки загружаются как original без неявного системного tint.
- `Resources/NinePatch`: два оригинальных xhdpi-фона кнопки и mdpi-фон диалога.
  `AndroidImages.ninePatch` удаляет служебную рамку при загрузке и читает чёрные
  маркеры растяжения. Углы и тени растягиваются через capInsets с исходной плотностью.
- `Resources/Fonts`: исходный `roboto_mono.ttf` из Android, Roboto Regular (variable,
  wght 100–900) из локального Android Studio layoutlib. Все начертания Roboto,
  включая Light (300), выбираются осью wght одного variable-файла. Отдельный
  Roboto Light не включается: его имя конфликтует с named instance variable-шрифта
  в Core Text на iOS 16 (ошибка 305).
  Android использует системный sans-serif; в iOS он поставляется явно, без подмены
  шрифтом San Francisco. Версия системного шрифта конкретного Android-устройства
  может отличаться от Android Studio; это проверяется при визуальной сверке.
- `Resources/Sounds`: девять исходных MP3/WAV: keypress_standard, level_complete,
  solution_is_answer, drop_coins, star_lose, timer_end, error, wrong, switch_numpad.
  Исключены четыре OGG аудиозадания будильника.
- `Resources/Licenses`: неизменённые шрифты сопровождаются copyright-уведомлениями
  из их name table и текстами Apache 2.0 / SIL OFL 1.1. Источники текстов:
  https://www.apache.org/licenses/LICENSE-2.0.txt и
  https://openfontlicense.org/documents/OFL.txt.

`tools/import_android_resources.py` воспроизводит каталог SVG и копирует ресурсы
Android без сторонних пакетов. Неизвестные конструкции вектора вызывают ошибку,
а не пропускаются. Скрипт не запускается как build phase и не изменяет Android.
`ANDROID_RESOURCES.json` содержит 178 путей и SHA-256 исходников;
`FONT_RESOURCES.json` — пути, SHA-256 и PostScript-имена двух шрифтов. Шрифт
Android Studio уже включены в проект, для сборки наличие Android Studio не нужно.

## Общие API

| Файл | Методы / типы | Назначение |
|---|---|---|
| `Design/AppTypography.swift` | `AppTypography.font`, `AppLabel.apply` | Однократная регистрация Roboto через Core Text; размеры из Android; системный Dynamic Type или сохранённый ручной масштаб 80–200%, без двойного увеличения |
| `Design/AndroidImages.swift` | `AppIcon.image`, `AndroidImages.ninePatch` | Именованные иконки и фоновые nine-patch |
| `Design/AppComponents.swift` | `AppButton`, tracking / `accessibilityActivate`, `AppHeaderView.apply`, `AppCardView` | Кнопки с состояниями и Android-иконками, заголовок 60 pt, карточка; цель касания не меньше 48 pt |
| `Design/AppDialogViewController.swift` | `init`, `viewDidLoad` | Общий модальный диалог, затемнение, Android-фон и кнопки; весь контент прокручивается при недостатке высоты; настройки шрифта поступают из переданного AppDataStore |
| `Services/AppFeedback.swift` | `play`, `haptic`, `stop` | Девять коротких эффектов, до пяти одновременных AVAudioPlayer, нативная тактильная отдача; учитываются сохранённые настройки |

`AppFeedback` использует ambient, учитывает беззвучный режим и смешивает звук с
музыкой пользователя. В фоне и при прерывании эффекты останавливаются и сами не
возобновляются. Разрешения микрофона, фоновый звук и зависимости будильника не нужны.
Конкретные игровые события подключаются при переносе игрового интерфейса: в
текущем меню звуковых демонстраций и тестовых кнопок нет. iOS haptics соответствуют
типам событий, точные миллисекундные паттерны Android не воспроизводятся.

## Подключение к оболочке

- `ShellScreenViewController.populateContent/addButton`: общие шрифты, кнопки,
  Android-иконки, заголовок и карточка счётчиков заменяют системные серые заглушки.
  Подписка на общий snapshot обновляет шрифт всех элементов, включая экраны в стеке.
- `AppRootViewController.viewDidLoad/loadProgress`: меню открывается сразу; данные
  читаются асинхронно без заставки и спиннера. Общий диалог с повтором показывается
  только при ошибке чтения. Сохраняются наблюдение настроек и сервис обратной связи.
- `BannerContainerView.showPlaceholder/apply`: общий шрифт и обновление масштаба
  текста. Владельцем единственного баннера остаётся корневая оболочка.
- Схема базы, Core Data, настройки и прогресс этим этапом не изменяются.

Пока используется базовое светлое оформление. Шесть тем, цвет и фоновые анимации —
этап 7. Компоновка и названия пунктов настоящего главного меню — этап 8. Экранные
заглушки остаются до переноса соответствующих разделов. Системный ripple Android
и детали анимации нажатия требуют последующей сверки; здесь используются
оригинальные нормальный/нажатый фон и состояния UIKit-контрола. Общий диалог готов
для будущих сценариев, при старте приложения искусственно не показывается.

## Сборка

Автотесты не создавались и не запускались. Финальная компиляция выполняется
`xcodebuild` для `iPhone - Victoria`; журнал `/tmp/math_tricks_stage6_build.log`.

iPhone 15 Pro Max (`com.antoni.mathtricks.free`) через devicectl. Установка
выполнена поверх приложения, без удаления данных. Единственное предупреждение
сборки — пропуск извлечения AppIntents metadata, этот SDK не подключён.
Совпадение интерфейса на устройстве и игровые звуки проверяет пользователь на
соответствующих этапах; компиляция не является проверкой визуального соответствия.

## Исправление запуска на iPhone Antoni (iOS 16.7.14)

- `AppButton.init`: ограничение ширины декоративного spacer активируется после
  добавления spacer в тот же UIStackView, где находится iconView. Исправлено
  исключение NSGenericException об отсутствии общего предка.
- `AppTypography.registration/font`: удалён отдельный Roboto-Light.ttf; Light
  выбирается через wght=300 в Roboto-Regular. Устранена причина Core Text 305.
- Служебные сообщения PreviewsAgentExecutorLibrary из debug-запуска не являются
  причиной этого исключения.
- `AppRootViewController.viewDidLoad/loadProgress` и `AppRouter.start`: главное меню
  открывается до завершения чтения данных. Удалены экран «Загрузка прогресса…»
  и спиннер; успешная загрузка не сбрасывает текущую навигацию.
- `ShellScreenViewController`: карточка счётчиков появляется только после получения
  snapshot, без подстановки нулевых значений и без изменения сохранённых данных.

Исправленная сборка успешно скомпилирована для iPhone (Antoni), iOS 16.7.14,
установлена после перезагрузки телефона и запущена с отключением отладчика.
Журналы: `/tmp/math_tricks_antoni_build.log`, `/tmp/math_tricks_antoni_install.log`,
`/tmp/math_tricks_antoni_launch.log`. Автотесты не запускались.
Чтение относится только к локальным Core Data / SQLite; облачный прогресс не
подключён и остаётся на этапе 21. Android и ios-legacy не изменялись.
