# Константы для ручной проверки iOS

Меняйте только `Math_Tricks/AppConstants.swift`, затем пересобирайте и запускайте
приложение из Xcode. Все три значения действуют и в Debug, и в Release.

| Константа | true | false |
| --- | --- | --- |
| `useTestAds` | Тестовые баннеры Google | Настоящие баннеры AdMob |
| `simulatePro` | PRO без оплаты: без рекламы и все трюки доступны | Обычная проверка покупки Apple |
| `unlockAllLevels` | Все трюки, уровни тренировок и заучивания, все сложности игры доступны | Обычные ограничения по прогрессу |

Начальные значения: `useTestAds = true`, `simulatePro = false`,
`unlockAllLevels = false`.

`unlockAllLevels` не включает PRO и не отключает рекламу. Для проверки рекламного
баннера не должно быть действующей PRO: выключение `simulatePro` не отменяет
настоящую покупку Apple. `useTestAds` выбирает тип рекламы, а не принудительно
показывает её вместо действующей PRO. Возрастные ограничения и согласие на рекламу
сохраняются.

Имитация не создаёт покупку в StoreKit и не записывает массовые открытия в базу,
архивы или облако. Выбор сложности сверх реально открытой хранится только в памяти
экрана выбора игры. После выключения переключателей действуют реальные покупки
и сохранённый прогресс. Пройденные во время проверки игры сохраняются обычным образом.

Перед публикацией поставьте **все три значения false** и пересоберите приложение.

## Изменённые файлы и методы

- `Math_Tricks/AppConstants.swift`: три доступных для редактирования переключателя.
- `Shell/BannerContainerView.swift`, `update`: выбор рекламного блока по `useTestAds`
  вместо автоматического выбора через `#if DEBUG`.
- `Services/AppPurchases.swift`, `hasFullVersion`, `refreshEntitlements`: реальная
  покупка хранится отдельно от имитации; все существующие проверки PRO используют
  результирующий доступ.
- `Data/AppDataStore.swift`, `applyingFullVersion`, `unlockTrick`: тестовый доступ
  ко всем трюкам поверх сохранённого прогресса, без списания монет.
- `Catalog/LevelsViewController.swift`: отрисовка, выбор и размеры ячеек уровней
  учитывают открытие всех замков.
- `ByHeart/ByHeartViewController.swift`: открытие и выбор всех уровней заучивания.
- `Game/GameModesViewController.swift`, `maximumLevel`, `currentLevel`, `saveLevel`,
  `launch`, `update`: все сложности и трюки доступны в тестовом режиме; выбранная
  тестовая сложность не повышает сохранённый максимум.
- `Multiplayer/MultiplayerSetupViewController.swift`, `start`: все трюки доступны
  и в обычной совместной игре при включённом переключателе.

Проект изменён: **ios/Math_Tricks**. **android/Math_Tricks** и **ios-legacy**
не изменялись. Тесты, установка и запуск на устройстве не выполнялись.
