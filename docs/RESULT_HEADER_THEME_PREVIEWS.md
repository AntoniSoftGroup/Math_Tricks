# Шапка результатов и предпросмотр тем

Изменён только современный iOS-проект `ios/Math_Tricks`. Android, `ios-legacy`,
архивы ZIP и AppStoreScreenshots не изменялись.

| Файл | Метод и изменение |
|---|---|
| `Math_Tricks/Game/GameResultTableView.swift` | `layoutSubviews()`: полоса результатов после игры/уровня использует общие `headerHeight(in:)` и `headerForegroundFrame(in:)`. Back, баланс и таблица лидеров центрируются по безопасной области шапки; на Duo учитываются камера и закругления. Содержимое начинается ниже фактической высоты шапки. Правило действует и при открытии результатов отдельного трюка. |
| `Math_Tricks/Settings/FontSamplePreview.swift` | `buildGame(_:header:)`: иконка монет использует template-изображение и акцент темы сразу при создании. Callback `appearanceUpdates` обновляет tint при изменении настроек и восстановлении кэшированной сцены. Общий компонент исправляет карточки выбора темы и настройки шрифта на всех устройствах. |
| `Math_Tricks/Theme/ThemePickerViewController.swift` | `viewDidLayoutSubviews()`: на iPad при ширине доступной области от 700 pt настройки находятся сбоку, их ширина составляет 38% области с ограничением 320–420 pt. Превью занимает оставшуюся ширину; карточка занимает до 90% своей области и ограничена её высотой с сохранением пропорций. В узком портретном окне iPad карточка ограничена пространством между настройкой шрифта и нижней панелью. Размер зависит от текущего окна, включая Split View. Прежний предел 282 pt остаётся только для портретного iPhone. |
| `docs/RESULT_HEADER_THEME_PREVIEWS.md` | Краткая выжимка файлов и методов. |

Проверка: компиляция Debug generic iOS без подписи, установки, запуска и тестов.
Доступен Xcode 26.6 / SDK 26.5. Нативная ветка API Duo требует SDK 27.1+;
положение элементов на Duo и размеры превью на iPad требуют визуальной проверки.
