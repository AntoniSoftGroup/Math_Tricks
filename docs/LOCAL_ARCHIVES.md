# Локальный архив прогресса (часть этапа 21)

`ProgressArchive` хранит собственный формат `math-tricks-ios-progress`, version 1,
расширение `.mathtricks.json`. Он включает настройки, счётчики, 107 приёмов,
уровни, одиночные и совместные сессии, реальные попытки и исторические графики.
Это полный формат iOS; optional-поле `androidBackup` сохраняет исходные таблицы
импортированного Android-архива без создания вымышленных сессий. Старые архивы
version 1 без этого поля остаются совместимы.

`AndroidProgressArchive.decode/nativeArchive` читает `math-tricks-progress` version 5
из GZIP, проверяет имена/состав таблиц, ключи, типы и диапазоны. Проекция получает
уровни, звёзды, монеты, разблокировки, отдельные рекорды выбранных приёмов, серию
дней и графики. Скоростные рекорды Android переводятся из десятых долей секунды.
Текущие настройки оформления, обычных напоминаний и отметки выбранных приёмов
iOS сохраняются: Android-файл не содержит этих настроек устройства.
`ImportedPracticeRecord` показывает сохранённые агрегированные измерения в
статистике; при наличии game_trick_groups они имеют приоритет над неполной
локальной детализацией Android после облачного восстановления. При экспорте
исходные группы сохраняются и дополняются только новыми iOS-попытками.
Неизвестный способ ввода не присваивается клавиатуре. Имена выражений
нормализуются по Android, поэтому измерения одного выражения объединяются.

`AndroidArchiveExport.androidEncoded` создаёт GZIP v5 отдельно от полного архива
через стандартный zlib SDK. Экспорт включает актуальную проекцию, измерения
настоящих iOS-попыток и исходные таблицы Android. Новые измерения уровней iOS
передаются через `cloud_level_metrics`; первые/последние сводки обычных и учебных
iOS-партий строятся из реальных сохранённых сессий. Их configuration имеет
префикс `ios-v1`; неизвестные исторические настройки клавиатуры/озвучивания
не приписываются партии, неизвестное completedAt остаётся 0. Формат Android не содержит настройки iOS и живые iOS-сессии.
Для полного восстановления приложения нужен архив iOS.

Ограничения: поддерживается версия 5, не версии 1–4 и не сетевой облачный формат.
Оба направления ограничены 50 MiB, в том числе после распаковки. Поля, которые
Android хранит как Int32, не обрезаются: непредставимый экспорт отклоняется.
В текущем Android `LocalFileBackup.restore` отклоняет числа ниже -1, хотя выбранный
набор может иметь `game_level_records.scope=-2`. iOS читает и сохраняет такой
архив, но отклоняет обратный Android-экспорт с этим scope, чтобы не выдавать
непринимаемый Android-файл. Полный iOS-архив остаётся доступен. Исходный Android
по правилам проекта не исправлялся. Первые/последние сводки новых партий на выбранном наборе не подменяются
другим scope. Их подробная история сохраняется полным архивом iOS.

`ArchiveViewController` открывает системный выбор файла, проверяет обычный файл
и размер до чтения, показывает дату и счётчики, затем запрашивает повторное
подтверждение замены. Импорт не выполняется при одном выборе файла.
Максимальный размер — 50 MiB. Нет SQL из архива и обращения к чужим контейнерам.

`validateSavedState()` / `validateSavedExample()` проверяют состав и диапазоны
сессии, типы ввода, уникальность ключей, конечность времени и арифметическую
согласованность примеров. Отсутствующие или несовместимые данные дают ошибку,
а не создают пустой прогресс. Непроверенный файл не меняет хранилище. Ревизия проверяется перед импортом:
изменение прогресса после открытия выбора файла отменяет замену.

`ProgressRepository.importProgressArchive()` сначала делает согласованную копию
новой SQLite через SQLite backup API, затем одной транзакцией заменяет проекцию
и новые данные. Для живых сессий создаётся новая generation: старый экран не
может повторно начислить награду после восстановления. Импортированные сессии
возобновляются с паузы, оригинальные Core Data и старые UserDefaults не меняются.
Прежние квитанции операций сохраняются. Импорт не имитирует решения или награды.

Экспорт, импорт и сброс пользовательской базы во время разработки не вызывались.
Проверка этого потока на устройстве остаётся пользователю. Выполняется только BUILD.
