## Идентичность приложения

Bundle ID и команда разработчика сохранены из старого iOS-проекта. Удалены
различающиеся SDK-переопределения: устройство и симулятор теперь используют
один ID. Это основа для будущего обновления приложения; перенос старой базы
и UserDefaults выполняется отдельно на этапе 4.

Внутренние имена target, продукта и Swift-модуля остаются `Math_Tricks`.
Отображаемое имя задаётся через `CFBundleDisplayName`, поэтому оно не требует
переименовывать будущую старую Core Data-модель или исходники.

Сопутствующие target настроены на ту же минимальную iOS и платформы:
`com.antoni.mathtricks.free.tests` и `com.antoni.mathtricks.free.uitests`.
Их тесты не запускались и не изменялись.

## Поддерживаемые системы

Минимальная iOS 15.0 выбрана вместо первоначальной 26.5, чтобы новая версия
не ограничивалась устройствами на самой новой системе. Имеющаяся SwiftUI-заготовка
компилируется с этой нижней границей; будущие API должны получать availability
проверки либо совместимую реализацию. Приложение не заявляет поддержку iOS ниже 15.

Удалены отдельные цели macOS и visionOS, их deployment targets и настройки
macOS sandbox. Также отключены Mac Catalyst, запуск iPhone/iPad-приложения
как приложения для Mac и режим Designed for iPad на Vision.

Ориентации повторяют старую iOS-версию. Ограничение конкретного игрового экрана,
например режима двух игроков, относится к реализации этого экрана. Системная
генерация launch screen и scene manifest сохранена; новый интерфейс ещё не создан.

## Версия и подпись

В файлах legacy указаны версия 1.7 и сборка 9; для разрабатываемого обновления
выставлены 1.8 и 10. Это рабочие значения, а не подтверждение доступного номера
в App Store Connect. Перед выпуском их нужно сравнить с реально опубликованными
версиями и загруженными сборками.

В настройках не закреплены имена сертификатов или UUID provisioning profile.
Xcode подбирает профиль для существующей команды и Bundle ID автоматически.
Готовность App Store-подписи и загрузки в магазин проверяется на этапе выпуска.

Game Center, реклама, покупки и облачные возможности подключаются на своих
этапах. Разрешения, зависимости и capabilities будильника не добавляются.

## Устройство для дальнейшей установки

По уточнению пользователя используется **iPhone (Antoni)**, iPhone 8 Plus,
iOS 16.7.14, UDID `ffc1fdd1f32b486c60ba0d0756e1e6329f76a1cc`.
При одновременно подключённом iPhone Victoria устанавливать на Antoni.
Устройство видно через `xcrun xctrace list devices` / `xcdevice list`, но не как
доступное в CoreDevice/devicectl из-за iOS 16. Для этапа 7 использована временная
сборка ios-deploy в `/tmp/math_tricks_ios_deploy/bin/ios-deploy` и LLDB-helper
`/tmp/math_tricks_antoni_launch.py`, который обрабатывает событие запуска перед
Detach. Установка без uninstall; данные приложения сохраняются. Эти утилиты не
включены в приложение и не являются его зависимостями.

Актуальное указание пользователя после этапа 7: после изменений выполнять только
build и сообщать результат. Автоматическую установку и запуск больше не выполнять;
пользователь запускает приложение сам. Это указание заменяет прежний порядок
автоматической установки из AGENTS.md. Antoni остаётся выбранным устройством,
если пользователь отдельно попросит установить приложение.
