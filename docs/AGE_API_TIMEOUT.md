# Защита фоновой проверки возраста от зависания

Изменён только современный iOS-проект `ios/Math_Tricks`. Android, `ios-legacy`,
архивы ZIP и AppStoreScreenshots не изменялись. Предыдущие изменения интерфейса
в рабочем дереве сохранены.

| Файл | Метод и изменение |
|---|---|
| `Math_Tricks/Services/AppAgeAssurance.swift` | `start(from:data:)`: фоновая проверка требований ограничена 10 секундами. При ошибке API возраст больше не сохраняется автоматически как пропущенный: штатная навигация открывает обычный нейтральный экран выбора возраста. Перед системным запросом Apple таймер отключается, чтобы пользователь мог ответить без ограничения времени. |
| `Math_Tricks/Services/AppAgeAssurance.swift` | `startBackgroundDeadline(for:)`: независимый таймер отменяет зависший запрос и сразу освобождает интерфейс, не ожидая реакции API на отмену. Идентификатор запроса исключает обработку запоздалого результата или ошибки, включая открытие системного окна после перехода к ручному вводу. |
| `Math_Tricks/Services/AppAgeAssurance.swift` | `finish(systemAgeRequired:)`: очищает таймер, идентификатор и ссылку на задачу, снимает блокировку проверки и сообщает навигации о готовности. |
| `Math_Tricks/Shell/AppRootViewController.swift` | `viewDidLoad()`, `updateAgeFlow()`, `isolated deinit`: вместо текста о проверке возраста выводится нейтральное «Подготовка…», только после 1 секунды ожидания. Задача показа отменяется при завершении проверки и освобождении контроллера. |
| `Math_Tricks/Resources/{ar,be,bn,de,el,en,es,fa,fr,he,hu,id,it,ja,ka,ko,pl,pt,ro,ru,th,tr,uk,vi,zh-Hans,zh-Hant}.lproj/AgeAssurance.strings` | Ключ `checking` заменён на `preparing` с переводом нейтрального сообщения на все 26 языков приложения. Перевод `required` для системного запроса уже имеется во всех этих локализациях. |
| `docs/AGE_API_TIMEOUT.md` | Выжимка файлов и методов. |

При ошибке/тайм-ауте не появляется предложение повторить проверку. Возраст
сохраняется после явного ввода или пропуска на обычном экране возраста. Если
пользователь уже сделал выбор ранее, стартовая проверка по-прежнему пропускается.
Обработка явного отказа делиться возрастом в обязательном системном запросе
Apple сохранена; отказ не считается ошибкой или зависанием API.

Проверка: компиляция Debug generic iOS (Xcode 26.6 / SDK 26.5) без подписи,
установки, запуска и тестов; синтаксис `.strings` проверен через `plutil`.
