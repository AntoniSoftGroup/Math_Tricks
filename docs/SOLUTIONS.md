# Этап 14 — пошаговые решения

`tools/import_solution_steps.py` переносит 224 метода построения шагов из Android
`TrickStepManager.java`: целочисленное деление, ветвления, разложения, правильные
ответы, координаты стрелок, выделения, переносы разрядов и длинное деление.
107 ID каталога имеют явный маршрут к исходным методам. Код воспроизводится
в `AndroidStepPort.hpp` и `AndroidStepDispatch.hpp`; SHA-256 источника указан в файле.
Оригинальный Android не изменяется. C++ использует ограниченные адаптеры строк
UTF-16/контейнеров; JVM и загружаемого кода нет. Выделенные модели освобождаются
ареной после сериализации. Ошибки вычисления возвращаются в Swift, не падая в UI.

`SolutionStep`/`SolutionArrow` читают JSON через C ABI. UIKit `SolutionSchemeView`
использует TextKit, Roboto Mono, исходные смещения символов, стрелки, подписи,
зачёркивания и выделения. Есть масштабирование/прокрутка схемы.
`SolutionViewController` показывает описание, ожидает ввод ответа шага, позволяет
вернуться, показать ответ ограниченное число раз, сменить способ для ×11/×8/×16.
Последний шаг можно отправить изображением через системный экран действий.
Арифметику шага, включая степени, можно открыть отдельным вложенным решением.
Подходящие способы (столбик, округление, константы, квадраты) подбираются по
StepExpressionParser Android. Ответ завершённого вложенного решения возвращается
в родительский шаг; новые результаты игры при этом не создаются. Правила также
доступны как интерактивная практика, без наград. Раскладка 123/789 учитывается.
Заполнение повторяющихся и дробных полей соответствует prepareEquation Android,
а смещения стрелок пересчитываются при вставке десятичного разделителя.

Игра остаётся на паузе под решением. Общие подсказки и три показа ответа шагов
принадлежат сессии. Учебный предпросмотр из правила не начисляет очки/монеты и
не создаёт игровых результатов. Существующий HTML-текст доступен отдельно.

Полная геометрическая сверка стрелок с Android и поведение вложенных
подвыражений остаются в визуальной/функциональной сверке этапа 24.
Проверка: Debug generic iOS — сборка успешна; автотесты, установка и запуск
не выполнялись.
