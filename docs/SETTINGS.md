# Этап 18 — локальные настройки

Актуальный список расхождений и исправлений 19.10.2026 —
[SETTINGS_PARITY.md](SETTINGS_PARITY.md). Ниже — историческое описание этапа 18;
точный состав текущего экрана и методов указан в новом аудите.

`SettingsViewController` показывает оформление, размер текста, 123/789, звук,
вибрацию, сигнал неверного ввода, способ ввода, озвучивание, ежедневные настройки,
политику, поддержку и системные настройки iOS. Рекламные/облачные пункты не
подменяются вымышленными подключениями: сервисная настройка отложена пользователем.

`TextAndKeypadViewController` сохраняет системный/ручной масштаб 80…200% и
раскладку, показывает настоящий предпросмотр. `AppSpeech` использует системный
AVSpeechSynthesizer, выбранный язык и режим «пример»/«с ответом», уважает звук,
silent mode и фон; в двухпользовательской игре озвучивания нет, как в Android.

Локальный сброс доступен только через два явных подтверждения в интерфейсе.
`ProgressRepository.resetLocalProgress` сначала создаёт согласованную SQLite
резервную копию через sqlite3_backup. Затем атомарно сбрасывает новые игровые
показатели и ставит постоянный маркер, запрещающий повторное добавление старых
проекций. Исходные Core Data/UserDefaults и старые резервные копии не изменяются.
Оформление и пользовательские предпочтения сохраняются. Generation блокирует
запись старой активной сессии из другого окна после сброса. Во время разработки
сброс не вызывался, пользовательский прогресс не обнулялся.

Проверка: Debug generic iOS без подписи — успешно. Тесты, установка и запуск
не выполнялись.
