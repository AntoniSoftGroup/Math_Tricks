# Локальная подготовка выпуска — начата, публикация не выполнялась

Bundle ID `com.antoni.mathtricks.free`, версия 1.8 (10), Team J2G688FEXG,
iOS 15+, iPhone/iPad сохранены. Профили и конфигурация App Store Connect
не менялись, архив для публикации не отправлялся.

Иконка AppIcon.png воспроизводится `tools/import_app_icon.swift` из оригинального
Android adaptive foreground на непрозрачном белом полотне 1024×1024.
Используется центральная область 72/108 Android; маску применяет iOS.
Источник и SHA-256 записаны в APP_ICON_SOURCE.json. Это конвертация исходного
ресурса, новый бренд или рисунок не создавался.

`PrivacyInfo.xcprivacy` описывает только текущую локальную реализацию:
UserDefaults своего приложения (CA92.1), монотонное время игровых таймеров
(35F9.1), метаданные собственных и выбранных пользователем файлов
(C617.1/3B52.1). Абсолютный systemUptime не сериализуется в сессию; сохраняются
только длительности. У приложения сейчас нет рекламного/аналитического SDK,
облачной передачи или трекинга. После подключения сервисов декларацию нужно
пересмотреть по фактическому составу приложения.
Причины сверены с [документацией Apple](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitype).

App Store privacy labels, реальные сертификаты выпуска, capabilities сервисов,
проверка обновления поверх версии 1.7 и публикация остаются отдельной работой.
Успешный unsigned BUILD не подтверждает готовность App Store-подписи или
сохранность данных на реальном обновлении. Эти действия не выполнялись.
