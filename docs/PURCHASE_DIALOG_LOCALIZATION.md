# Окно покупки: переводы и второстепенное восстановление

Изменения только в ios/Math_Tricks:

- `Math_Tricks/Services/AppPurchases.swift`, методы `present`, `show`: отдельный
  локализованный заголовок «Полная версия»; покупка с ценой первой, затем «Закрыть»;
  «Восстановить покупки» в отдельной второстепенной секции. Восстановление остаётся
  доступным и при активной PRO, и если запрос товара не сработал.
- `Math_Tricks/Design/AppDialogViewController.swift`, `Action`, `viewDidLoad`: флаг
  `isSecondary` по умолчанию выключен. Для восстановления используется разделитель,
  кнопка без основной заливки и меньшая подпись; область нажатия остаётся не менее
  48 pt. Другие окна используют прежнее оформление.
- `Math_Tricks/Resources/*.lproj/Interface.strings`: по 11 ключей для всех 26 языков:
  ar, be, bn, de, el, en, es, fa, fr, he, hu, id, it, ja, ka, ko, pl, pt, ro, ru,
  th, tr, uk, vi, zh-Hans, zh-Hant. Переведены заголовок, кнопки, преимущества,
  активный статус, недоступность покупки, ожидание одобрения, ошибки проверки и сети,
  отсутствие покупки при восстановлении.
- `docs/IOS_PURCHASES.md`: обновлена информация о локализациях и виде окна.

Настройки, Android и ios-legacy не изменялись.

`git diff --check`; Debug generic iOS без подписи — BUILD SUCCEEDED.

Тесты, установка и запуск не выполнялись. Переносы длинных надписей, RTL и внешний
вид в темах на устройстве не проверялись.
