# Этап 22 — ежедневная практика и напоминания

`DailyProgressEngine` переносит правила Android LocalProgressStore: локальные
календарные дни, одно начисление серии за день, защита от перевода часов назад,
закрытие предыдущего дня, накопление страховки за 7 выполненных дневных целей,
восстановление пропуска только после выполнения цели текущего дня. Открытие
экрана не начисляет решений/страховок. Все принятые реальные ответы, включая
тренировку и двух игроков, обновляют дневные показатели в той же транзакции,
что и основное начисление. Постоянные ID операций защищают от повтора.

`DailySettingsViewController` сохраняет цель 1/2/3/4/5/10/20/30/40/50/75/100,
сложность Android (1…20, затем с шагом 5 до 100), время и разрешение напоминаний.
Выбор приёмов использует те же сохранённые отметки каталога, как SelectTricksFragment.
Ежедневная игра работает без ограничения времени и заканчивается по дневной цели;
монеты начисляются по обычному циклу реальных решений, без отдельного вымышленного
бонуса за дневную цель. Дневные записи доступны графику серии.

`DailyNotificationService` использует только UNUserNotificationCenter и обычный
UNCalendarNotificationTrigger. Разрешение запрашивается только при включении
переключателя пользователем; запуск приложения его не запрашивает. Нажатие
уведомления открывает ежедневную практику после загрузки данных/первого запуска.
Текст напоминания общий: iOS не обновляет динамические счётчики в содержимом
повторяющегося локального уведомления при полностью закрытом приложении.
Актуальные числа показываются в самом приложении. Звуков/служб/экранов будильника
нет. Напоминания используют обычный системный звук уведомления.

Проверка: Debug generic iOS без подписи — успешно. Тесты, установка и запуск
не выполнялись; разрешения и доставка на устройстве требуют ручной проверки.
