# Этап 8 — первый запуск и главное меню

Реализованы отдельные `AgeScreenViewController`, первоначальный `ThemePickerViewController`
и `MainMenuViewController`. `AppRouter.reconcileOnboarding` заменяет корневой экран
без анимации и без сохранения первого запуска в стеке возврата.

Возраст 0…99 хранится только локально в optional `AppSettings.onboarding`. Отсутствие
поля у существующих настроек означает завершённый первый запуск. Старые DEFAULTS,
маркер инициализации и записи Core Data также исключают повторное прохождение.
Сохранение первоначальной темы завершает поток одной транзакцией репозитория.

Меню повторяет порядок Android: общий счётчик и настройки, ежедневная панель,
одиночная/совместная игра, тренировка, заучивание, статистика, оценка и поддержка.
В landscape кнопки перегруппировываются в два ряда; Instagram скрыт до 16 лет.
У старых пользователей с неизвестным возрастом ссылка доступна. Будильника нет.
Счётчики используют реальный snapshot; до загрузки выводится «—».

Ссылки открываются по нажатию. Поддержка открывает окно составления письма,
оценка использует StoreKit. Android Play Store и вымышленные product ID отсутствуют.
Движок ежедневной серии и уведомления остаются этапом 22.

Клавиша удаления возраста имеет поверхность клавиатуры без видимой текстовой подписи,
но с accessibilityLabel. Удалены неиспользуемые поля старой заглушки меню.
