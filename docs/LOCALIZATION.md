# Этап 23: переводы

`tools/import_localizations.py` воспроизводит таблицы Main, MainRich, Catalog, Steps и
Interface для 26 языков Android: en, ru, ar, be, bn, de, el, es, fa, fr, he, hu,
id, it, ja, ka, ko, pl, pt, ro, th, tr, uk, vi, zh-Hans, zh-Hant.

Названия, правила и формулы 107 приёмов, группы, описания шагов, меню и общие
подписи берутся из Android. Нативные сообщения iOS хранятся отдельно в
`tools/localization`. Инвентарь покрытия — `LOCALIZATION_REPORT.json`.
Отсутствующие в исходном Android переводы правил используют его английский
вариант. Это явно отмечено числом catalogFallback, а не выдаётся за полный
перевод всех исходных текстов на каждый язык. Нативные iOS-подписи переведены.

Ресурсы string и integer имеют в Android разные пространства имён. Импортёр
не позволяет integer `option_theme` подменить одноимённый перевод заголовка.
Параметры Android `%d/%s` преобразуются в `%lld/%@`, включая позиционные индексы.
Строки будильника и его зависимостей не импортируются. MainRich сохраняет
исходные small/b/i для счётчиков меню; AndroidRichText.inline строит их через
атрибуты UIKit. Подписи размера шрифта и игрового заголовка берутся из Android.

Язык выбирает iOS по локалям приложения. Список knownRegions согласован с
каталогами .lproj. Математические схемы всегда имеют направление слева направо,
кнопки возврата и переходов зеркалируются для RTL. Числа форматируются локалью.
Заголовки тем и экранов не содержат закреплённых русских подписей в Swift.

Debug generic iOS собран. Визуальная проверка длинных переводов, RTL, VoiceOver
и системного размера шрифта на устройствах ещё не выполнялась: установка,
запуск и автотесты исключены текущим указанием пользователя.
