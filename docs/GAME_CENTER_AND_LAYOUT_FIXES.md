Идентификаторы Game Center, включая две добавленные таблицы:

| Рейтинг | ID |
| --- | --- |
| До предела | `lb_game_single_free` |
| Минутный штурм | `lb_game_minute_free` |
| На скорость | `lb_game_speed_free` |
| Без времени | `lb_game_noTime_free` |
| Уровни тренировки | `lb_tricks_levels_free` |
| Уровни таблицы умножения | `lb_byHeart_multiplication_levels_free` |
| Всего решено | `lb_total_solved_free` |
| Серия дней | `lb_main_day_streak` |
| Максимальный игровой уровень | `lb_game_level` |

Для «На скорость» сохранён старый формат `Int(Float(seconds) * 10)`, в десятых секунды; меньший результат лучше. Пройденные уровни считаются по `bestScore > 0`, как в старом iOS. Кнопка серии дней на главном экране открывает `lb_main_day_streak`; кнопка рядом с игровым уровнем — `lb_game_level`. В новые таблицы отправляются `daily.streak` и `maximumLevel`; сохраняется только улучшение, большее значение лучше. Таблицы созданы пользователем в App Store Connect.

Статическая проверка горизонтального режима:

| Экраны | Результат проверки кода |
| --- | --- |
| Главное меню | Есть перестройка шапки, меню и нижних кнопок. |
| Выбор игрового режима | Есть отдельная горизонтальная компоновка выбора сложности и режимов. |
| Одиночная игра | Перестраиваются ввод, служебные кнопки и название приёма; учтён перенос клавиатуры. |
| Совместная игра / два игрока, их настройка и результаты | Есть смена оси и равенство размеров областей игроков. |
| Результаты одиночной игры / дочернего приёма | Явная компоновка, сводка слева и таблица справа; независимая прокрутка. |
| Правило и пошаговое решение | Есть разделение списка шагов и схемы; размеры списков меняются при повороте. |
| Темы | Есть отдельная боковая панель; исправлена высота длинной подписи шрифта. |
| Размер шрифта | Исправлена отсутствовавшая горизонтальная компоновка. |
| Настройка клавиатуры | Карточки располагаются рядом, содержимое прокручивается. |
| Уровни | Сетка меняется с 3 на 5 столбцов с учётом масштаба текста. |
| Каталог приёмов, «Наизусть», примеры, настройки, архивы, ежедневные настройки | Содержимое находится в таблицах или прокручиваемых областях. |
| Таблица умножения, графики | Размеры содержимого привязаны к текущей области просмотра. |
| Возраст | Подпись и значение возраста располагаются горизонтально; высота клавиатуры адаптируется. |
| Диалоги | Ограничена высота относительно safe area, содержимое прокручивается. |

Это проверка кода, не визуальная проверка всех экранов на устройстве. Сборка Debug для generic iOS без подписи успешна; тесты, установка и запуск не выполнялись. Повторное зависание «Без времени» исправлялось переработкой компоновки, но исчезновение зависания требует ручного подтверждения. Реальный вход, доступность таблиц и отправка счёта в Game Center также не проверялись на устройстве.

Оставшиеся отличия интерфейса: рекламные подарки/бонусы/дополнительные попытки ещё не подключены; предпросмотры решения и каталога упрощены; диалоги не являются пиксельной копией Android; в экспортируемой карточке нет полного блока сравнения прогресса.

Справка Apple по использованным API: [инициализация Game Center](https://developer.apple.com/documentation/gamekit/initializing-and-configuring-game-center), [GKLeaderboard](https://developer.apple.com/documentation/gamekit/gkleaderboard).
