# Единый экран облачного прогресса и файлов

В настройках оставлен один пункт «Облачный прогресс», с названием и иконкой Android. Он открывает обычный экран iOS вместо Android-диалога. Внутри один прокручиваемый список с двумя отдельными карточками.

Первая карточка содержит статус аккаунта, вход через Apple/Google, связывание способов входа, кнопки облачного сохранения и восстановления рядом, выбор баланса при конфликте, сброс, выход и удаление аккаунта. Облачный формат и правила Firestore не менялись. Кнопка уже связанного провайдера остаётся видимой с явным статусом.

Сброс сохраняет дневную цель и служебные настройки, как в Android; отметка сброса статистики растёт даже при переводе часов устройства назад.

Вторая карточка содержит «Сохранить резервную копию в файл», «Восстановить из файла», описание и статус операции из Android. Основной экспорт создаёт совместимый `.mathtricks.gz`. Дополнительная кнопка «Сохранить полную копию iOS» сохраняет нативную историю и настройки в `.mathtricks.json`.

Как в Android, проценты облачного хранилища групп трюков, отдельных уровней и примеров показываются от 80%. Отдельно отмечается статистика уровней выше 10, остающаяся только локально. Размер считается после gzip и Base64, по существующим ограничениям. Нажатие предложения сохранить файл прокручивает к файловой карточке.

На время экспорта, системного выбора файла, проверки и подтверждения импорта операции облака приостанавливаются. Отмена освобождает блокировку. Импорт проверяет тип, размер, структуру и исходную ревизию прогресса; перед заменой сохраняется локальная резервная копия. После импорта прогресс остаётся виден на этом экране. Для Android-файла сохраняются текущие настройки устройства; нативная копия iOS восстанавливает и настройки, о чём говорится в подтверждении. Возраст текущего пользователя не заменяется. Ошибка планирования уведомления после успешного импорта не выдаётся за ошибку восстановления.

## Файлы и методы

| Файл | Изменения |
| --- | --- |
| `Cloud/CloudViewController.swift` | `buildContent`, `applyAppearance`, `update`: две тематические карточки; `refreshUsage` — размеры и локальная статистика; `showFileSection` — переход к файлам. |
| `Archives/ProgressFileActions.swift` | Методы файловой карточки в расширении общего контроллера. Старый отдельный `ArchiveViewController` удалён; проверки импорта и оба формата сохранены. |
| `Cloud/CloudSync.swift` | `beginFileOperation`, `endFileOperation`, `safe`: взаимное исключение файловых и облачных операций. |
| `Settings/SettingsViewController.swift`, `Navigation/AppNavigation.swift` | Удалены отдельный пункт файлов и маршрут архивов. |
| `Shell/AppRootViewController.swift` | Предложения файловой копии ведут на общий экран. |
| `Resources/*/Interface.strings (`cloud.*`)` | Все 26 языков iOS. Общие строки взяты из Android, специфичные тексты iOS и короткие названия кнопок переведены отдельно. |
| `tools/import_cloud_localizations.py` | Повторный импорт строк Android и генерация нативных подписей; проверяет наличие исходных переводов. Запуск из iOS-проекта: `python3 tools/import_cloud_localizations.py`. Android не изменяет. |

Проверка: компиляция Debug и проверка строковых ресурсов. Тесты и запуск на устройстве не выполнялись по правилам проекта. Вёрстку на разных устройствах и языках, выбор файлов и реальный обмен с Firebase ещё нужно проверить вручную.

Изменён текущий iOS. Android и iOS legacy не изменялись.

Компактная версия: отступы карточек и между ними — 8 pt, внутренние интервалы — 6 pt. Основные действия облака и файлов, а также способы входа сгруппированы по два в строке. Минимальная область нажатия сохранена 44 pt, текст может переноситься и масштабироваться. Подписи явно указывают назначение: сохранение в облако, восстановление из облака, сохранение в файл и восстановление из файла. `CloudText.text` использует общую таблицу `Interface` с префиксом `cloud.` и резервной английской локализацией. Основной импорт локализаций вызывает импорт облачных подписей, чтобы не удалять их при повторной генерации.
