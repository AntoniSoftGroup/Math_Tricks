# Этап 17 — результаты, статистика и графики

`PracticeStatistics` объединяет реальные попытки одиночных и двухпользовательских
сессий. Самостоятельным считается решение без ошибок, исправлений, подсказки и
показанного ответа; среднее и лучшее время вычисляются только по измеренным
самостоятельным решениям. Старые агрегатные показатели не превращаются в
вымышленные подробные попытки.

`StatisticsViewController` показывает примеры, приёмы, наиболее медленные примеры
и приёмы для повторения. Есть фильтр ввода, диапазоны сложности, первое/лучшее
время, сортировка и страницы по 20 строк. Подробности завершённой партии
открываются из GameViewController. Строка примера ведёт в решение, строка приёма —
в его подробную статистику. Изображение видимой страницы отправляется через
системный UIActivityViewController только по действию пользователя.

`GraphViewController`/`AppLineChart` рисуют графики UIKit на iOS 15. Старые точки
сохраняют исходные даты/единицы; скорость legacy переводится из десятых секунды
существующим слоем совместимости. Новые графики раздельны для обычных и выбранных
приёмов. Непройденная игра на скорость не создаёт рекорд. До появления данных
показывается пустое состояние. График серии получает реальные дневные записи
после этапа 22. График общего количества показывает решения по новым сессиям,
без реконструкции неизвестной временной шкалы старого счётчика.

Новые попытки также сохраняют фактический ответ/предложенные варианты, когда они
известны. Отсутствовавшие поля старых снимков optional и не заполняются задним числом.
