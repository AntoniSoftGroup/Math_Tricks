# Этап 15 — заучивание и таблица

`ByHeartViewController` показывает числа 2…99 и 21 уровень для каждого числа.
Диапазоны взяты из Android `ByHeartGetInterval`: первый 2…5, далее блоки по пять,
двадцатый 96…99, последний 2…99. Уровни 1 и 21 открыты изначально, остальные —
по сохранённым разблокировкам. Последний уровень содержит 50 примеров; перед
обычным уровнем `ByHeartExamplesViewController` показывает произведения диапазона
и позволяет выбрать 10…50 примеров. Игра использует общий GameSession.

Существующие результаты и звёзды читаются из LegacyProgressIndex/новой SQLite.
Допустимое количество уровней multiplication увеличено с прежнего ограничения
10 до 21, без изменения исходных моделей Core Data. Нет искусственно пройденных
уровней. `allLevels(scope:)` получает все сохранённые уровни одним запросом.

`MultiplicationTableViewController` показывает сетку 1…10 с заголовками и список
девяти блоков, как Android. Вид сохраняется отдельно. Таблица доступна из
заучивания и из решения; возврат сохраняет учебный шаг и паузу игры.

не выполнялись. Визуальная сверка остаётся этапом 24.
