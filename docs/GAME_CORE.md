# Этап 11 — игровое ядро

`Game/Core/AndroidExampleGenerator.cpp` воспроизводит 107 арифметических генераторов
из Android `player/Player.java`. `tools/import_example_generator.py` сохраняет ветви,
диапазоны и приведения исходных формул, удаляет интерфейсные вызовы и генерирует
C ABI для Swift. Целочисленные вычисления расширены до int64_t. Источник и SHA-256
записаны в сгенерированном файле. Модуль не содержит UIKit и служб Android.

`MathExample` — операнды, отображаемые дроби, ответ и тип операции. `GameSession`
отделяет состояние игры от контроллера: монотонное время, пауза, ввод, подсчёт,
звёзды, подсказки/пропуски и журнал реальных попыток. Семь последних выражений
исключаются при генерации, с ограничением 51 попытка, как в Android.

Новая SQLite повышена до user_version=2 добавлением `game_sessions`. Миграция
не изменяет исходные Core Data и игровые показатели. Сессия и начисления могут
записываться одной транзакцией `ProgressOperation.gameSession`; повтор операции
имеет прежний постоянный ID. Sequence препятствует записи устаревшего снимка.
Сохранённая сессия восстанавливается на паузе, время фона не считается решением.

Сборка Debug generic iOS без подписи прошла. Тесты не создавались и не запускались.
